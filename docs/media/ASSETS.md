# Presentation assets

`architecture.html` is the editable, offline source for the architecture figure. `architecture.svg` is its self-contained vector export. They describe the current local workspace, durable evidence and supported employer boundaries; the diagram is explanatory artwork, not an application screenshot.

The figure uses the product's framed-sheet neutrals and restrained teal accent. IBM Plex Sans Regular and SemiBold are embedded to preserve offline rendering. These are unmodified IBM Plex fonts, licensed under the [SIL Open Font License](OFL-IBM-Plex.txt). Original font files and their license are also retained in the project's `public/fonts/` directory. No remote font request is required.

The SVG contains its own styles and accessible title/description. The HTML keeps a local horizontal scroller on narrow screens so labels remain readable. Text alternatives also appear beside the figure in the README.

The diagram source and export retain no account data, machine paths or runtime secrets.

`product-hero.html` and `social-preview.html` are editable editorial frames around `application-document.png`. Their PNG exports use the existing local browser renderer. The social preview is 1200×630; it is supplied as an optional repository preview and has not been uploaded by the presentation task.

The four application captures are unmodified screenshots of the running software: `application-document.png`, `discovery.png`, `posting-text-comparison.png` and `needs-you.png`. They use curated synthetic candidates, employers, feeds, documents and source changes, with campaigns off. They are not the built-in first-use seed or evidence of live applications. Editorial framing adds captions; it does not reconstruct interface elements or retouch the underlying screenshots.
